Tasks Performed by Computer

1. Data Input

Entering data and instructions into the computer using input devices like keyboard, mouse, and scanner.

2. Data Processing

The computer processes data by performing calculations and following instructions.

3. Data Storage

The computer stores information for future use using hard disks, flash drives, and memory devices.

4. Data Output

The computer presents processed information through output devices like monitor, printer, and speakers.

Input → Processing → Storage → Output

DATA INPUT
  • What it is: The stage where raw data is collected and entered into the system.
  • Examples: Typing with a keyboard, clicking a mouse, scanning a barcode.
  • Purpose: Convert raw data into meaningful information.
