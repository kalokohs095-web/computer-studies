Introduction to Software


What is Software?

Software is a set of programs and instructions that tells the computer what to do. It helps the computer perform tasks and cannot be touched physically.


Common Software for Daily Use

  • Operating System (Windows, Android)
  • Web Browser (Google Chrome)
  • Word Processor (Microsoft Word)
  • Media Player (VLC)
  • Communication Software (Whatsapp, Zoom)
  • Antivirus Software (Avast, Window Defender)

Why Do Computers Not Work Without Software

Computers cannot work without software because software gives instructions to the hardware. Without software:

  • The computer cannot start
  • It cannot process data
  • It cannot perform tasks
  • Hardware cannot function properly

The hardware is the physical part of the computer, but software control it. For example:
A keyboard is hardware but without software, the computer cannot understand what you type.


Simple Example

A computer without software is like a car without a driver. It has all the parts but cannot work.

How Application Software Relies on System Software

1. System software provides the platform

System software creates the environment where application software can run. Without an operating system, applications like word processors or browsers have no foundation to operate on.

2. Access to hardware devices

Application software relies on system software to communicate with hardware such as the keyboard, mouse, printer, and display screen.

3. Management of memory and processor time

The operating system controls memory usage and allocates processor time, ensuring applications run efficiently without crashing the system.

4. Installation and execution

Without system software, application software cannot be installed, launched, or executed on a computer system.

5. Communication between software and hardware

System software ensures smooth communication between applications and hardware, allowing everything to work together efficiently.

Software management is the process of organizing, controlling, maintaining, updating, and monitoring software in a computer system. It involves installing software, updating it, protecting it, and ensuring that it works properly.

Software Development Life Cycle (SDLC)

Software Development Life Cycle (SDLC) is a step-by-step process used in developing software or applications. SDLC helps developers plan, design, develop, test, and maintain software properly.


Stages (Phases) of SDLC

1. Planning

In this stage, developers identify the purpose, goals, cost, and resources needed for the software.

Project managers identify resources, timeline, cost, and possible risks before development begins.

2. Requirement Analysis

Developers gather information about what users need from the software.

This stage ensures that the software will meet the needs of users.

3. Design

The structure and appearance of the sotware are designed.

Design helps developers understand how the system will function before coding begins.

4. Implementation (Coding)

Programmers write the actual code for the software

Different programming languages and development tools are used to build the software.

5. Testing

The software is tested to identify and fix errors or bugs.

Testing ensures the software works correctly and meets user requirements.

6. Deployment

The completed software is installed and released for users.

It can be deployed on servers, computers, or mobile devices depending on the system.

7. Maintenance

After release, developers update and improve the software.

Maintenance includes fixing bugs, improving performance, and adding new features.


Software Development Models

Software development models are methods or approaches used in developing software. These models guide software developers through the stages of planning, designing, coding, testing, and maintaining software.


Model Description Advantages Disadvantages
Waterfall Model The waterfall model is a step-by-step method where one phase must be comppleted before moving to the next phase. (e.g. requirements → design → coding → testing → implementation → maintenance) Simple and easy to understand, Easy to manage, suitable for small projects Difficult to make changes after development starts, Errors may be discovered late
V-Model (Verification and Validation Model) The V-Model is similar to the waterfall model, but testing is done alongside each deveopment stage. Early testing improves quality, easy to detect errors Expensive to change requirements, Not flexible
Iterative Model In iterative Model, software is developed in small parts called iterations. Each version is improved repeatedly until the final product is completed. Easy to improve the software, problems can be corrected early Requires good planning, can consume more time and resources
Spiral Model The Spiral Model combines repeated development with risk Analysis. It is mainly used for large and complex projects. (e.g. planning → risk analysis → engineering → evaluation) Good risk management, suitable for large projects Expensive, complex to manage
Prototyping Model In this model, a sample version called a prototype is created first to help users understand the system before the final software is developed. Helps users give feedback early, reduces misunderstanding Can waste time if many changes are made, Final system may have weak design
Agile Model The Agile Model develops software in small sections with continuous feedback and improvement. Flexible and fast, encourages teamwork and customer involvement Difficult to manage large teams, required skilled developers

Importance of Software Development Models

  • Improves software quality

A software license explains how the software can be used, copied, shared, or modified.

Software Piracy

Software piracy is defined as the unauthorized copying, distribution, reproduction, modification, sale, installing, downloading, or use of copyrighted software without explicit permission from the original owner or vendor.

💡 WASSCE Theory Tip: Always emphasize terms like "unauthorized copying", "copyrighted software", and "without vendor permission" when answering Section B essay questions to score full marks!

Types of Software Piracy

The West African Examinations Council frequently asks candidates to state and explain these specific types:

1. Softlifting (End-User Piracy)

Purchasing a single legal software license and installing it onto multiple computers at home, school, or work in violation of the End-User License Agreement (EULA).

2. Hard-Disk Loading

Occurs when computer hardware sellers pre-install unauthorized copies of software onto computer hard drives before selling them to make the purchase look more attractive.

3. Software Counterfeiting

Illegally duplicating, packaging, and selling fake software designed to closely imitate genuine branded commercial products (complete with fake packaging and logos).

4. Internet Piracy

Downloading or sharing unauthorized commercial software, key generators ("keygens"), or cracks through file-sharing websites, torrent platforms, or warez networks.


Effect of Software Piracy

⚠️ Effects on Users

  • Malware & Ransomware: Unlicensed software often contains hidden keyloggers or viruses.
  • No Official Updates: Pirated copies cannot receive legal security patches or bug fixes from developers.
  • No Technical Support:Users cannot access vendor customer support or user manuals.

📉 Effects on Developers & Economy

  • Financial Loss: Deprives tech developers of rightful revenue needed for growth.
  • Stifles Innovation: Discourages young programmers and software startups from creating new tools.
  • Legal Penalties: Leads to fines and criminal prosecution for copyright infringement.


Preventive Measures (Anti-Piracy Solutions)

  • Product Activation Keys / License Codes: Requiring unique online serial numbers to validate software installation.
  • Digital Rights Management (DRM): Technical access control technologies that restrict unauthorized copying.
  • Copyright Laws & Legal Commissions: Strict enforcement of intellectual property rights by national bodies.
  • Use of Free & Open-Source Software (FOSS): Encouraging legal, free alternatives like Linux, LibreOffice, and Blender.
  • Holographic Labels: Placing tamper-proof physical security holograms on official software packaging.

Software Activation

Software activation is an essential component of modern digital rights management (DRM) and licensing. It allows software vendors to prevent illegal usage while granting valid users seamless feature access.

Simple Definition (Standard)

Software activation is the process of verifying and unlocking software for legal use by using a valid product key or license key.


🎯 Key Objectives


  • Prevent Piracy: Restricts unauthorized duplication and distribution.
  • Verify Authenticity: Checks that the installed software copy is genuine.
  • Validate Purchase: Confirms the license was lawfully bought.
  • Protect Intellectual Property: Safeguards developer work and investments.
  • Grant Full Access: Unlocks restricted application features.

💡 Core Importance


  • Protects software vendors against financial losses.
  • Guarantees genuine, uncorrupted software for users.
  • Ensures access to vital security patches & updates.
  • Enables standard technical support services.
  • Maintains legal compliance with End User Agreements.

🔑Product Keys vs. License Keys

Though frequently used interchangeably, product keys and license keys perform distinct roles during software licensing.


Product Key


A unique alphanumeric code provided by the software developer, typically entered during setup to authenticate the copy.


Example Format

AB12C-DE34F-GH56J-KL78M-NP90Q

  • Consists of letters and numbers separated by hyphens.
  • Unique to each physical or digital copy.
  • Used directly during installation or activation.

Licence Key


A digital authorization certificate or code granting explicit legal rights to install and operate software under defined terms.

  • Confirms legal user entitlement and ownership.
  • Can permit installation on one or multiple machines.
  • Often stored digitally inside cloud accounts.

Primary Function Used mainly to technically activate software. Gives legal permission to use software.
Usage Stage Usually entered during installation setup. Stored digitally or registered during setup.
Verification Goal Validates that the software copy is genuine. Validates that the user has permission to use it.

What is a EULA?

An End User License Agreement (EULA) is a legal contract between a software developer (or vendor) and the user purchasing or installing the application.


Why is a EULA Important?

A EULA establishes clear legal boundaries protecting both parties, but primarily safeguards the software provider:


  • Protects Intellectual Property: Prevents unauthorized copying, resale, or distribution.
  • Limits Liability: Shields the developer from legal damages if the software crashes or causes data loss.
  • Defines Allowed Use: Outlines whether the software can be used for personal or commercial purposes.
  • Enables Revocation: Grants the vendor the right to revoke your access if rules are broken.

Common Terms Found in EULAs

While often lengthy, most EULAs include these core clauses:

1. Grant of License

Specifies what access you receive (e.g., non-exclusive, non-transferable, single-device use).

2. Usage Restrictions

Explicitly bans reverse engineering, pirating, sharing account credentials, or modifying code.

3. Disclaimer of Warranties

States the software is provided "AS IS," meaning developers don't guarantee zero bugs.

4. Termination Clause

Explains how and when the agreement can be ended by either party.

Types of Backup


A. Based on backup method

Understanding how different backup methods process and save data changes:



  • Full Backup: Copies all selected files. Easy to restore, but uses the most storage space and time.
  • Incremental Backup: Copies only files changed since the last backup of any type. Saves storage and time; restoring can be complex.
  • Differential Backup: Copies all files changed since the last full backup. Faster to restore than incremental, uses less space than repeated full backups.

Internet & Email Security

Internet and email security involves protecting hardware, user accounts, and personal data from unauthorized access or malicious threats while using online services.


1. Safe Web Browsing


Definition: Safe web browsing means navigating the internet carefully and securely to avoid malicious websites, scams, malware, and unauthorized access to personal information.



Core Safe Browsing Practices


  • Visit trusted, verified websites.
  • Check the address bar (URL) before entering credentials.
  • Avoid clicking suspicious links, pop-ups, or unexpected banner ads.
  • Keep your web browser and operating system updated to patch vulnerabilities.
  • Use strong, unique passwords combined with Multi-Factor Authentication (MFA).
  • Log out of personal accounts when using shared or public computers.

2. Secure Websites (HTTPS)


HTTPS stands for Hypertext Transfer Protocol Secure. It is the secure version of HTTP that uses encryption protocol (TLS/SSL) to protect data transmitted between a web browser and a website.



Key Features & Identification

  • URL begins with https:// instead of http://.
  • A closed padlock icon is displayed next to the URL in modern browsers.

Importance of HTTPS

  • Encryption: Scrambles sensitive data (e.g., passwords, credit cards) during transit.
  • Data Integrity: Prevents attackers from altering transmitted data unnoticed.
  • Authentication: Helps confirm connection to the authentic domain server.

Important Correction / WASSCE Note: HTTPS guarantees that your connection to the site is encrypted; it does not guarantee the site itself is genuine or honest. Fraudulent or phishing websites can also obtain valid HTTPS certificates.

3. Phishing Attacks


Definition: A social engineering attack aimed at tricking individuals into revealing sensitive credentials, financial details, or personal data by posing as a trustworthy entity.

Common Examples

  • A fake email from a "bank" requesting urgent account verification via a provided link.
  • Spoofed social media login pages created to steal credentials.
  • Messages pretending to be from an exam body or school requesting registration info.

Prevention Measures

  • Inspect sender email addresses carefully for minor spelling variations.
  • Avoid clicking direct links inside unexpected emails; type official URLs manually.
  • Never share passwords, PINs, or Multi-Factor Authentication codes.

Quick Self-Test: A message says: "Your bank account is locked! Click here to unlock immediately." What should you do?



4. Email Scams


Definition: Fraudulent messages sent via email designed to deceive recipients into sending money, exposing information, or executing harmful actions.


Common Scam Types

  • Advance-Fee / Lottery Scams: Falsely claiming you won a prize but must pay a processing fee.
  • Employment Scams: Offering fake jobs that require up-front payment for tools or training.
  • Fake Invoices/Receipts: Demanding payment for services you never ordered.

Prevention Guidelines

  • Be critical of offers that seem unnaturally lucrative or overly urgent.
  • Do not open unexpected email attachments, especially .exe, .zip, or script files.
  • Verify unexpected requests via an established, independent communication channel.

5. Spam Emails


Definition: Unsolicited, bulk-sent electronic messages, usually sent for commercial advertising, promotional schemes, or distributing malicious content.


Impact of Spam

  • Consumes inbox storage space and bandwidth resources.
  • Wastes user time sorting through unwanted emails.
  • Acts as a vehicle for delivering phishing links and malware attachments.

Handling & Management

  • Utilize automated spam filters provided by your email service.
  • Avoid replying to spam or clicking "Unsubscribe" inside unverified, suspicious emails (this confirms your address is active).
  • Flag suspicious items as "Spam" or "Phishing" inside your email portal.

6. Safe Downloading Practices


Definition: The protocol of downloading files, media, and applications from trusted sources while applying checks to eliminate security threats.



Best Practices for Safe Downloading

  • Download applications strictly from official developer sites or verified app stores.
  • Avoid pirated or "cracked" software, as these frequently contain hidden malware/trojans.
  • Verify file extensions prior to execution (e.g., watch out for double extensions like document.pdf.exe).
  • Keep automated antivirus scanning enabled for newly downloaded files.
