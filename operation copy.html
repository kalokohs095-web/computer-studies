Introduction to Software


What is Software?

Software is a set of programs and instructions that tells the computer what to do. It helps the computer perform tasks and cannot be touched physically.


Common Software for Daily Use

  • Operating System (Windows, Android)
  • Web Browser (Google Chrome)
  • Word Processor (Microsoft Word)
  • Media Player (VLC)
  • Communication Software (Whatsapp, Zoom)
  • Antivirus Software (Avast, Window Defender)

Why Do Computers Not Work Without Software

Computers cannot work without software because software gives instructions to the hardware. Without software:

  • The computer cannot start
  • It cannot process data
  • It cannot perform tasks
  • Hardware cannot function properly

The hardware is the physical part of the computer, but software control it. For example:
A keyboard is hardware but without software, the computer cannot understand what you type.


Simple Example

A computer without software is like a car without a driver. It has all the parts but cannot work.

How Application Software Relies on System Software

1. System software provides the platform

System software creates the environment where application software can run. Without an operating system, applications like word processors or browsers have no foundation to operate on.

2. Access to hardware devices

Application software relies on system software to communicate with hardware such as the keyboard, mouse, printer, and display screen.

3. Management of memory and processor time

The operating system controls memory usage and allocates processor time, ensuring applications run efficiently without crashing the system.

4. Installation and execution

Without system software, application software cannot be installed, launched, or executed on a computer system.

5. Communication between software and hardware

System software ensures smooth communication between applications and hardware, allowing everything to work together efficiently.


Application Software Installation and Updates


1. Installation Process

  • Download the software from a trusted source.
  • Check system requirements before installation.
  • Run the installer file.
  • Follow on-screen instructions.
  • Accept the license agreement.
  • Complete the installation and restart if required.
The installation process prepares the software so it can run properly on the computer.

2. Software Updates and Upgrades

  • Software Update: Improves an existing version by fixing bugs, improving security, and adding small features.
  • Software Upgrade: Replaces an old version with a newer version that has major changes and new features.
Updates are usually free and frequent, while upgrades may be paid and released less often.

Quick Example

If you install Microsoft Word 2019 on your computer:

  • Installing Word 2019 is the installation process.
  • Fixing errors in Word 2019 is a software update.
  • Changing from Word 2019 to Word 2021 is a software upgrade.

What is Software Management?

Software management is the process of organizing, controlling, maintaining, updating, and monitoring software in a computer system. It involves installing software, updating it, protecting it, and ensuring that it works properly.


Importance of Software Management

  • Improves computer performance
  • Increases computer security
  • Reduces software errors and problems
  • Ensures software is updated
  • Saves time and cost
  • Improves organization of programs

Goals and Objectives of Software Management

  • To maintain software performance
  • To ensure software security
  • To keep software updated
  • To manage software installation properly
  • To improve productivity
  • To reduce system failure
  • To ensure proper use of software

Software Development Life Cycle (SDLC)

Software Development Life Cycle (SDLC) is a step-by-step process used in developing software or applications. SDLC helps developers plan, design, develop, test, and maintain software properly.


Stages (Phases) of SDLC

1. Planning

In this stage, developers identify the purpose, goals, cost, and resources needed for the software.

Project managers identify resources, timeline, cost, and possible risks before development begins.

2. Requirement Analysis

Developers gather information about what users need from the software.

This stage ensures that the software will meet the needs of users.

3. Design

The structure and appearance of the sotware are designed.

Design helps developers understand how the system will function before coding begins.

4. Implementation (Coding)

Programmers write the actual code for the software

Different programming languages and development tools are used to build the software.

5. Testing

The software is tested to identify and fix errors or bugs.

Testing ensures the software works correctly and meets user requirements.

6. Deployment

The completed software is installed and released for users.

It can be deployed on servers, computers, or mobile devices depending on the system.

7. Maintenance

After release, developers update and improve the software.

Maintenance includes fixing bugs, improving performance, and adding new features.


Software Development Models

Software development models are methods or approaches used in developing software. These models guide software developers through the stages of planning, designing, coding, testing, and maintaining software.


Model Description Advantages Disadvantages
Waterfall Model The waterfall model is a step-by-step method where one phase must be comppleted before moving to the next phase. (e.g. requirements → design → coding → testing → implementation → maintenance) Simple and easy to understand, Easy to manage, suitable for small projects Difficult to make changes after development starts, Errors may be discovered late
V-Model (Verification and Validation Model) The V-Model is similar to the waterfall model, but testing is done alongside each deveopment stage. Early testing improves quality, easy to detect errors Expensive to change requirements, Not flexible
Iterative Model In iterative Model, software is developed in small parts called iterations. Each version is improved repeatedly until the final product is completed. Easy to improve the software, problems can be corrected early Requires good planning, can consume more time and resources
Spiral Model The Spiral Model combines repeated development with risk Analysis. It is mainly used for large and complex projects. (e.g. planning → risk analysis → engineering → evaluation) Good risk management, suitable for large projects Expensive, complex to manage
Prototyping Model In this model, a sample version called a prototype is created first to help users understand the system before the final software is developed. Helps users give feedback early, reduces misunderstanding Can waste time if many changes are made, Final system may have weak design
Agile Model The Agile Model develops software in small sections with continuous feedback and improvement. Flexible and fast, encourages teamwork and customer involvement Difficult to manage large teams, required skilled developers

Importance of Software Development Models

  • Help organize software development work
  • Improves software quality
  • Reduces development errors
  • Saves time and cost
  • Makes project management easier

Software Installation & Uninstallation


Meaning of Software Installation

Software installation is the process of copying and setting up a software program on a computer so that it can work propely. During installation, the computer creates folder, and prepares the software for use.


Examples of software that can be installed include:

  • Adobe photoshop
  • Google Chrome
  • VLC Media Player
  • Microsoft Word

Types of Software Installation

1. Full Installation

All files and features of the software are installed on the computer.

Advantage

  • All features are available

Disadvantage

  • Uses more storage space

2. Custom Installation

The user chooses the features or components to install

Advantage

  • Saves storage space

Disadvantage

  • Some features may not be installed.

3. Network Installation

Software is installed from a network server instead of a local disk or flash drive

Advantage

  • Easy to manage in organization

Disadvantage

  • Requires a stable network connection

Steps in Software Installation

1. Download or Insert Software

Get the software from the internet or a storage device.


2. Open the Installer

Double-click the setup file (e.g., setup.exe).


3. Follow Instructions

Accept terms and choose installation location.


4. Install

Click install and wait for the process to complete.


5. Finish

Launch the software after installation.


How to Open and Close Software

Open: Double-click the software icon or use the start menu.

Close: click the "X" button or press Alt + F4.



Importance of Proper Installation

  • Prevents software errors
  • Improves performance
  • Protects your computer from viruses
  • Ensures compatibility

Some software comes with its own uninstall tool.


Example

Disadvantages of Incorrect Uninstallation

What is Software Maintenance

Software maintenance is the process of modifying and updating software after it has been deployed to correct faults, improve performance, or adapt it to a new environment.


Types of Software Maintenance


Types Meaning Example
Corrective Maintenance This involves fixing errors or bugs found in the software after it has been released Repairing a program that crashes during use.
Adaptive Maintenance This involves modifying software so it can work in a new environment or with new hardware and operating systems. Updating software to work with a new operating system
Perfective Maintenance This involves improving the performance or adding new features to the software Add new tools or option to an application
Preventive Maintenance This involves making changes to prevent future problems and improve reliability. Updating security features to stop future attacks

Keeping your software updated and secure is essential for protecting systems, improving performance, and preventing cyber threats.

Role of Software Managers / Developers


Software managers and developers play an important role in ensuring that software systems are properly planned, developed, and maintained.


  • Planning Software Projects: They define project goals, timelines, and resources needed to complete the project successfully.
  • Managing Software Teams: They coordinate developers, assign tasks, and ensure teamwork for efficient development.
  • Ensuring Quality Software: They test and monitor software to ensure it meets standards and works without errors.
Good software management ensures that projects are completed on time, within budget, and meet user requirements.

Advantages of Proper Software Management

  • Better Performance: Well-managed software runs faster and more efficiently.
  • Improved Security: Proper management helps protect systems from viruses and cyber threats.
  • Longer Software Life: Regular updates and maintenance extend the lifespan of software systems.
Organizations that practice proper software management experience fewer system failures and better overall productivity.

What is a Software Licensing?

Software licensing is the legal permission or agreement that allow a user to use a software program under specific terms and condition set by the software developer or company.
A software license explains how the software can be used, copied, shared, or modified.


Purpose of Software Licensing


  • Protects Developers Rights: Protect the ownership of the software creator.
  • Defines Terms of Use: Explains how the software an be used.
  • Prevents Illegal Use: Stop software piracy and unauthorized copying.
  • Generates Revenue: Allows developers to earn money
  • Ensures Proper Usage: Guides users on legal and correct use.
  • Control Distribution: Cotrols who can access and share the software
  • Supports Updates: Licensed users receive updates and support.

Legal Agreement Between User and Developer

A legal agreement between the user and the software developer is a formal contract that explains the rules and conditions for using software.

It states what the user is allowed to do with the software and what the developer is responsible for providing.

This agreement is usually found in a Software License Agreement or End User License Agreement (EULA)


Rights and Responsibities of Users


Right of Users


  • Right to Use the Software: Users have the right to use the software according to the license agreement.
  • Right to Receive Support: Licensed users may receive technical support and updates.
  • Right to Privacy: Users have the right to protection of their personal information.
  • Right to Use the Software: Users have the right to use the software according to the license agreement.
  • Right to Access Licensed Features: Users can access licensed features.

Responsibities of Users


  • Follow Software License Agreements: Users should obey the terms and conditions of the software license and avoid illegal copying or distribution.
  • Use Software Properly: Software should be used for its intended purpose and according to the instructions provided by the developer.
  • Protect Software from Unauthorized Access: Users should use strong passwords and keep login details confdential to prevent unauthorized access.
  • Keep Software Updated Users should install updates and patches to improve performance and security.
  • Report Errors and Problems: Any bugs, errors, or security issues should be reported to the software developer or administration.
  • Learn How to Use the Software: Users should acquire the necessary knowledge and skills to use the software effectively.
